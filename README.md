## Theme descriptions
### 1. System of linear equation solving
Solving a system of linear equations using the Jacobi, Gauss-Seidel, and minimal residual iterative methods.
### 2. Eigenvalue search
Calculation of eigenvalues ​​with QR method and Power Method.
### 3. Single nonlinear equation solving
Solving equations using simple iteration, Newton’s method, single-point and multi-point iteration methods, and the secant method.
### 4. System of nonlinear equation solving
Solving a system of nonlinear equations using the simple iteration method and Newton's method.
### 5. Numerical integration
Calculating an integral to a specified precision using the rectangle method, the trapezoidal rule, Simpson's rule, and Gauss-Christoffel quadrature formulas.
### 6. Polynomial approximation
Interpolation using a Lagrange polynomial on a uniform grid, a Lagrange polynomial with an optimal choice of nodes, and Chebyshev polynomials.
### 7. Ordinary differential equation solving
Numerical solution of the Cauchy problem using Euler's method, the Runge-Kutta method, the Adams scheme, and the predictor-corrector scheme. Numerical solution of boundary value problems using the shooting method, the finite difference method, and the collocation method.
